# Automatic Number Plate Detection YOLO OCR
Automatic Number Plate Detection and Recognition using YOLO, Easy OCR ,OpenCV and Streamlit. Detects vehicle license plates and extracts plate numbers from images and videos.

# Automatic Number Plate Detection and Recognition

## Project Overview
This project detects vehicle number plates using YOLO
and extracts the plate text using EasyOCR.

## Technologies Used
- Python
- YOLO
- EasyOCR
- OpenCV
- Streamlit
- Jupyter Notebook

## Features
- Vehicle number plate detection
- Number plate text recognition
- Image-based detection
- Video-based detection
- Streamlit web interface

## Applications
- Intelligent transportation systems
- Parking management
- Vehicle monitoring
